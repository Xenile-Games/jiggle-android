# Jiggle for Android

The latest test build of **Jiggle**, the jigsaw puzzle game by Xenile Games.

**Download:** [jiggle.apk](https://github.com/Xenile-Games/jiggle-android/releases/download/latest/jiggle.apk)

To install it on an Android phone or tablet:

1. Open the link above on the device, and download `jiggle.apk`.
2. Open the downloaded file. If Android asks, allow your browser or file manager to install unknown apps.
3. Install, then open **Jiggle**.

To update later, download the same link again and install over the old one. Your progress is kept.

This is a test build, not a store release. It is updated whenever the Android app improves.
